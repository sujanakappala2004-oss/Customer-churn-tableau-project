# 📊 Customer Churn Analysis Dashboard (Tableau)

## 📌 Project Overview
This project analyzes customer churn behavior using a telecom dataset with 7,000+ customer records.  
The goal is to identify key factors affecting customer retention and visualize insights using an interactive Tableau dashboard.

---

## 🎯 Objective
To understand customer behavior patterns and identify the main drivers of churn to help improve customer retention strategies.

---

## 📊 Dashboard Overview
The Tableau dashboard includes:

- KPI Metrics:
  - Total Customers: 7043  
  - Churned Customers: 1869  
  - Churn Rate: 26.5%

- Visual Analysis:
  - Contract Type vs Churn
  - Customer Tenure vs Churn
  - Monthly Charges vs Churn (Scatter Plot)

---

## 🔍 Key Insights
- Customers with month-to-month contracts show the highest churn rate  
- New customers (low tenure) are more likely to churn  
- Higher monthly charges are associated with increased churn risk
